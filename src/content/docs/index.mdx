## Who this is for

You already ship software. You know an API from a database, you've used Python (FastAPI) and a modern frontend, and you have ~2+ years of experience. You **don't** need a course that teaches you what a function is — you need one that teaches you what changes when the core of your system is a probabilistic model.

## The path

1. **Mindset and foundations**: how LLMs behave, cost, reliability, streaming, structured output, context engineering.
2. **AI-native UX**: streaming interfaces and generative UI with the Vercel AI SDK.
3. **Retrieval**: embeddings from scratch, then production RAG.
4. **Quality**: evals, error analysis, CI regression gates.
5. **Agents**: tools, harnesses, LangGraph, MCP, safe execution and security.
6. **Production**: observability, cost and performance, deployment.
7. **The field**: forward-deployed engineering.
8. **Case studies and capstones**: full system designs (starting with Claude Code) and four portfolio projects.
