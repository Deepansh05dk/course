## Who this is for

You already ship software. You know an API from a database, you've used Python (FastAPI) and a modern frontend, and you have ~2+ years of experience. You **don't** need a course that teaches you what a function is — you need one that teaches you what changes when the core of your system is a probabilistic model.

## The path

1. **Foundations**: how LLMs behave, calling them well, streaming, structured output.
2. **Building blocks**: RAG, tool use, agents, MCP.
3. **Quality**: evals, error analysis, regression testing.
4. **Production**: observability, cost/latency, security, deployment.
5. **The field**: forward-deployed skills, like scoping, customer data, and pilots that go live.
6. **Capstones**: four portfolio projects that mirror real FDE engagements.
