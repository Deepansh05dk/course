## The customer: Acme Logistics

*Acme Logistics (fictional) moves freight for 4,000 business customers.* Their support team of 60 agents handles about 9,000 tickets a week:

- **45%** are "where is my shipment?" questions, which need a lookup in the shipment database.
- **25%** are policy questions (refunds, damages, customs), which need answers from 200 PDFs, many of them outdated.
- **20%** are requests that need an action: refunds, address changes, re-deliveries.
- **10%** are angry escalations.

Average first response time is 9 hours. The VP of Support wants it under 1 hour **without** hiring 40 more people, and **without** the bot making promises the company can't keep.

You're the engineer deployed to make that happen. Your product is **Relay**.

```text
relay/
├── app/
│   ├── main.py          # FastAPI app
│   ├── config.py        # settings from env
│   ├── llm.py           # the ONE module that talks to model providers
│   └── routes/
├── evals/               # datasets + eval scripts (from Module 1)
├── tests/
├── docs/architecture.md # your evolving diagram
├── .env                 # never committed
└── pyproject.toml
```

:::tip[Put the provider behind one module]
Every model call goes through `app/llm.py`. When you add tracing (Module 9), caching (Module 10) or a second provider (Module 11), you change one file instead of thirty. This is the cheapest architecture decision you'll ever make.
:::

## Smoke test: your first call, measured from day 1

Even the smoke test logs tokens and cost. That's the habit this course builds.

```python
# smoke.py
import time

import anthropic

PRICE_PER_M = {"input": 4.00, "output": 20.00}  # USD per million tokens; check your provider's pricing page

client = anthropic.Anthropic(timeout=30.0)  # reads ANTHROPIC_API_KEY

start = time.perf_counter()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1000,
    messages=[{"role": "user", "content": "In one sentence: what does a logistics support agent do?"}],
)
elapsed = time.perf_counter() - start

# The response is a list of content blocks (it can include "thinking" blocks),
# so collect the text blocks instead of assuming content[0] is text.
text = "".join(block.text for block in msg.content if block.type == "text")
cost = (
    msg.usage.input_tokens * PRICE_PER_M["input"] + msg.usage.output_tokens * PRICE_PER_M["output"]
) / 1_000_000

print(text)
print(f"stop_reason={msg.stop_reason} in={msg.usage.input_tokens} out={msg.usage.output_tokens} "
      f"latency={elapsed:.2f}s cost=${cost:.5f}")
```

```bash
uv run --env-file .env python smoke.py
```

You should see an answer plus a line like `stop_reason=end_turn in=24 out=61 latency=2.1s cost=$0.00132`. Those four numbers (finish reason, tokens, latency, cost) will appear in every trace you build from now on.

<Practice>

- **Warm-up:** run the smoke test five times. Record latency and output tokens for each run. How much do they vary?
- **Stretch:** add `gitleaks` (or `detect-secrets`) as a pre-commit hook in `relay/`, then try to commit a fake key and watch it get blocked.
- **Boss level:** turn the smoke test into `app/llm.py` with a function `complete(prompt) -> Completion` that returns text **and** a metrics object (tokens, latency, cost, stop reason), and appends a JSON line to `logs/calls.jsonl`. You've just built a tiny observability layer, and the next module builds on it.

</Practice>
